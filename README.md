# Mia & Lark: Lost in the Woods

A cozy, cartoon 3D adventure game that runs in your web browser.

Mia wandered off the path picking flowers and got lost in a huge forest. With her bestie Lark, she finds her lost things, reaches the village of Willowbrook, makes new friends, and helps everyone with quests.

## How to play

Open `index.html` in a web browser, or play it online with GitHub Pages.

| Key | What it does |
| --- | --- |
| Arrow keys or WASD | Walk |
| Space | Talk, sit, open doors |
| L | Ask Lark for help |
| G | Hug Lark |
| J / K | Jump / spin |
| Q | Quests |
| I | Mia's bag |
| P | Mia's phone (text friends, play games) |
| M | Bigger map |
| 1 to 7 | Use things in the bar |

## Things to do

- Explore 12 places, from sunflower fields to snowy mountains
- Visit Willowbrook: the bakery, café, clothes shop, pet store, restaurant, park, fishing pond and a 2-story mall
- Finish quests for 10 coins each, and finish them all for a 100-coin prize
- Decorate Mia's house, cook in her kitchen, and adopt a pet
- Seasons follow the real calendar, and night comes every few minutes
- Save your game in 3 save slots

## Note

When the game runs inside Claude, people in the village text back with Claude. On GitHub Pages, they reply with simple built-in messages instead.

Made with three.js.
